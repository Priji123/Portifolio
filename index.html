M.Tech Thesis Project · Mar Baselios College DOCUMENTED

Multi-Texture Building Surface Crack Detection

10,000+ Image Pairs Processed Without Manual Annotation
  • Designed and implemented an Attention U-Net deep learning system in Python for pixel-level crack segmentation across diverse surface textures and real-world environmental conditions.
  • Engineered an automated data labelling pipeline using Frangi filter-based pseudo-mask generation, processing 10,000+ image pairs without manual annotation.
  • Implemented custom loss functions (Tversky Loss, Dice Coefficient) and a mixed-precision TensorFlow training pipeline, demonstrating end-to-end system design from data ingestion to model evaluation.
Python TensorFlow Attention U-Net Frangi Filter Pseudo-Masks Tversky Loss & Dice Coefficient Image Segmentation
TECHNICAL DECISIONS & IMPLEMENTATION (8-Part Record)

1. Problem [DOCUMENTED]: Pixel-level crack segmentation across diverse surface textures faces severe class imbalance and background texture noise, while manually annotating 10,000+ image masks is impractical.

2. Engineering Approach [DOCUMENTED]: Automated Frangi filter pseudo-mask generation pipeline (10,000+ image pairs) paired with an Attention U-Net trained in a mixed-precision TensorFlow pipeline using Tversky Loss and Dice Coefficient.

3. Workflow: Surface Image → Preprocessing → Frangi Pseudo-Mask Generation → Attention U-Net → Semantic Segmentation → Tversky/Dice Evaluation.

4. Technical Concepts (Expandable):
Image Classification vs. Semantic Segmentation [CONCEPT]

Classification predicts one label per patch; semantic segmentation outputs dense pixel-level crack topology maps.

Frangi Pseudo-Label Generation & Attention Gates [DOCUMENTED]

Frangi Hessian eigenvalues isolate tubular cracks to generate pseudo-masks for 10,000+ image pairs; Attention Gates weight U-Net skip connections to suppress surface texture noise.

Tversky Loss & Dice Coefficient vs. General IoU [DOCUMENTED / CONCEPT]

Tversky Loss and Dice Coefficient are documented thesis components handling class imbalance; IoU is explained in the lab as a general segmentation concept.
